## 自动化

- `pnpm check`：全量 TypeScript 类型检查。
- `pnpm build`：生产前端打包。
- `pnpm test`：登录、越权、CSRF、会话撤销、最后管理员保护、告警滞后与抑制、SSRF、任务互斥、备份恢复、日志脱敏。
- `python -m unittest discover -s deploy/tests`：远程白名单拒绝、服务停止顺序、worker超时中断、容器缺失拒绝、API就绪后启动后台任务。

## Linux Docker 集成测试

当前 Windows 开发环境没有 Docker，因此真实容器控制必须在专用 Linux 测试机完成。测试只使用 `vcm-control-test` 项目，绝不能修改脚本指向业务项目。

```bash
python3 deploy/integration-test.py
```

脚本创建独立测试容器，验证 stop/start/restart、日志及依赖未变动，finally 清理该固定测试项目。它不安装 SSH/sudo 配置，不连接生产业务。镜像首次运行需联网下载。

## 浏览器验收路径

1. 未登录进入登录页，错误密码有明确提示；正确账号进入项目总览。
2. 两项目名称、域名、技术栈、部署状态正确；运行未知不伪造。
3. 搜索 ProjectManager 只显示该项目；状态筛选及返回项目目录工作。
4. 项目详情独立显示内网、公网和 TCP，历史可查，SSH 未就绪时控制禁用。
5. 管理员可编辑项目和主机、创建只读用户；只读用户无启停与日志入口，API也拒绝。
6. 1440px和1180px桌面无页面级横向溢出；390px窗口保持桌面布局并整体横向滚动。

## 生产接入验收

- 从可信控制台核实 SSH 指纹后安装入口，验证两项目服务标签与状态。
- 确认 db、redis、api 具有可用健康检查。
- 控制中心通过最终 HTTPS Tunnel 域名登录；未登录 API 401；viewer 写操作 403。
- 维护窗口内确认后执行真实启停，核实 db/redis StartedAt、容器 ID 不变。
- 测试 Webhook 接收端故障/恢复通知，验证投递日志与维护抑制。
- 重建控制中心容器后数据保留；演练 SQLite 备份恢复。

只读 SSH 连接在当前环境由于缺少可信主机密钥而被拒绝，未自动接受未知主机指纹。未发布公网、未创建生产 SSH 授权、未停止或重启现有业务。
