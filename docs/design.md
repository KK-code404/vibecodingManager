# CONTROL·DECK 界面规范

本次重设计以用户提供的《控制中心-Codex视觉与交互规范.md》和 `prototype.html` 为视觉与交互依据，替换原先的浅色 Ant Design 界面。原型中的虚构资产、随机指标、模拟登录、已启用 Access 的文案不属于生产数据要求。

## 视觉与布局

- 深空遥测站：近黑背景 `#0A0D12`，面板 `#10151C`，磷光青 `#3EDCB2`，警告 `#FFB454`，异常 `#FF5D5D`。
- 默认等宽字体，中文使用本机字体回退；不依赖外部字体 CDN。CRT 扫描线、呼吸指示点、内联 SVG 波形与图表沿用原型。
- 固定 198px 侧栏，主区域 18px / 20px 内边距，三列项目卡片，四列 KPI，面板 10px 圆角，间距 12px。
- 桌面最小宽度 1180px；更窄窗口整体横向滚动，不折叠侧栏或卡片。此规则替代上一版移动端自适应设计。
- 原生 React 组件与内联 SVG，已移除 Ant Design 和图标库依赖。按钮、表单、下拉、开关、确认弹窗、Toast 均使用统一样式。
- 支持键盘焦点、原生 dialog 焦点约束、Escape 关闭、语义标签与减少动画偏好。

## 数据口径与交互边界

- 初始清单仍是两项目、一台 VM；不存在演示用的八项目或三节点。
- 在线项目按 SSH 实测运行状态计数；健康告警单独计数。公网失败不会被当作容器停止。
- `/api/telemetry` 聚合过去 24h 的内网检查：平均值、P95/P99 使用成功样本，可用率为成功样本占全部样本比例，包含维护时采样，并非按时长计算的 SLA。
- 图表 96 个 15 分钟区间，无样本时保持空缺。最大观测故障时长不跨越超过 90 秒的采集缺口。
- 今日告警以北京时间自然日统计失败事件，未投递和被抑制的事件仍是已有事件。通知是否启用在设置中单独显示。
- 顶部 ECG 是装饰波形，已提供非实时指标的无障碍说明；不伪装 CPU、流量或心跳数据。
- 资源缺失、SSH 未连接、过期数据均显示未知或 `—`。只有实际配置的健康规则显示生效，CPU/内存/磁盘没有假造阈值告警。
- 日志按服务读取最多最近 50 行、每 10 秒刷新，可暂停；错误关键字只做高亮。事件页标记已读只影响视图，不删除审计。
- 停止与重启继续要求确认受影响服务，任务异步执行。未核对 SSH 映射时按钮禁用，数据库和 Redis 保持只监控。
- 保留真实 8 小时 Session、服务端 RBAC/CSRF、无公开注册；没有用附件中的模拟成功逻辑替换安全控制。
- 原型中的分支和 Cloudflare 接入方式作为可选登记字段，不执行拉取、部署或 Tunnel 配置；固定探测周期与阈值展示为只读。
